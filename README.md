# destinytravels
destiny Travels REST API

# Project Overview

Destiny Travels is a RESTful API developed using Node.js, Express.js, MongoDB, and Mongoose. It allows users to manage travel destinations by adding, viewing, updating, filtering, and deleting destination records.

The project follows the MVC (Model–View–Controller) architecture and demonstrates CRUD operations, database integration, filtering, sorting, and pagination.
